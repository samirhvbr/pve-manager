### 5. Multi-tenancy — decidir o caminho

Análise em [`docs/multi-tenancy.md`](../docs/multi-tenancy.md). Três dos quatro
requisitos são nativos; **quota de RAM/vCPU não existe no PVE**.

- **(a) Controle manual do dimensionamento** — custo zero de desenvolvimento,
  custo operacional recorrente.
- **(b) Contabilidade no fork** — soma por pool via API, mostra
  consumido/contratado. Dá visibilidade, mas **não é enforcement** sem validação
  no caminho de criação/edição de VM.

Só decidir depois de saber se o modelo comercial vende limite de recurso.
