## Queue

### A. Reboot both nodes for the kernel fix — NEW, SECURITY

The fix for CVE-2026-99999 (Linux IPv4 `checksum_start`) ships in
`proxmox-kernel` 7.0.14-24 and later, and **only a reboot applies it**.
Installed: b3p1 has -24, spx1 has -25. Running: b3p1 is on 7.0.14-19, spx1 is
on 7.0.6-2.

- One node at a time. With two hosts, the other host loses quorum until the
  rebooted one is back ([`docs/cluster.md`](../docs/cluster.md)).
- **Before b3p1 reboots:** eight restored copies have `onboot: 1` and would
  start with their originals' MACs, three of them with a live NIC on `vmbr0`.
  Decide on their `onboot` first. On 2026-10-27 the owner chose not to change
  it yet.
- b3p1 cannot reach `download.proxmox.com` or `security.debian.org` over IPv4.
  Only the internal mirror answers, so its `apt update` is stale. Its packages
  came over as `.deb` files relayed from spx1. Fix the route, or point b3p1 at
  the mirror for these suites too.
- This reboot is also item 2 below: check `http://<ip>/` afterwards.

### B. Guest migration from the standalone host — NEW, in progress

Status on 2026-10-27: none of the 35 guests is validated. 20 have a stopped
copy on b3p1, and all 20 have their volumes and bridges in place. 4 have a
PBS backup that has not been restored yet. 11 have no backup yet. No restore
has run since 2026-10-22.

What is left, beyond the restores themselves:

- **Network delivery.** The source LAN and its VLANs must reach `nic4` on the
  cluster nodes. A capture on 2026-10-16 showed the LAN does not reach it. Gate
  each guest on the capture in `docs/guest-migration.md`.
- **Per-guest validation and cut-over:** a final backup with the original
  stopped, start the copy, test, and set `onboot: 0` on the source.
- **A backup target for the cluster** (item C) before the source host is
  switched off.
- Then decommission the source host.

### C. Backups for the cluster — NEW, BLOCKS the end of B

The cluster has no backup storage of its own. The PBS used for the migration
is a transfer area, not a backup plan. The owner has not decided this yet.
